# COVID-19 in India - Tableau Dashboard

## Project Overview

An interactive Tableau dashboard analyzing the impact of COVID-19 across India using state-wise, demographic, vaccination, and testing data. The dashboard uses visual storytelling and spatial analysis to explore case trends, vaccination coverage, demographics, testing activity, and healthcare resources across Indian states.

## Objectives

- Analyze state-wise COVID-19 case trends over time.
- Compare confirmed, cured, and death cases across states.
- Examine first and second dose vaccination coverage.
- Analyze vaccine-wise dose distribution.
- Study COVID-19 cases across age groups and genders.
- Analyze state-wise testing activity and laboratory availability.
- Use geographic visualization to compare COVID-19 impact across states.

## Dataset

The dashboard uses publicly available COVID-19 datasets for India covering:

- State-wise case statistics.
- Vaccination data.
- Testing data.
- Laboratory availability.
- Age group information.
- Gender-wise demographic data.

Spatial analysis uses an Indian states shapefile for geographic visualization.

| Tool | Purpose |
|------|---------|

## Data Cleaning & Transformation

- Consolidated COVID-19 datasets from multiple categories.
- Structured state-wise case, vaccination, testing, and demographic data.
- Prepared data for time-series and comparative analysis.
- Integrated spatial data for state-level mapping.
- Organized demographic and vaccination fields for interactive visualization.

## Data Analysis

The analysis covers COVID-19 cases, vaccination, demographics, testing, and healthcare infrastructure.

Key analyses included:

- State-wise confirmed, cured, and death cases over time.
- First dose versus second dose vaccination coverage.
- Vaccine-wise distribution across Covaxin, Covishield, and Sputnik V.
- Total COVID-19 deaths by state.
- Age group and gender distribution.
- State-wise testing activity.
- Laboratory availability across states.

## Dashboard

The Tableau dashboard includes:

- **State-wise Time Series:** Trends in confirmed, cured, and death cases.
- **Vaccination Comparison:** First dose versus second dose coverage.
- **Vaccine Distribution:** Dose distribution across Covaxin, Covishield, and Sputnik V.
- **COVID-19 Death Map:** Choropleth map showing total deaths by Indian state.
- **Demographic Analysis:** Age group-wise and gender-wise breakdown.
- **Testing Analysis:** State-wise testing data and laboratory availability.

## Key Insights

- COVID-19 impact varied considerably across Indian states.
- State-wise trends highlight differences in confirmed, recovered, and death cases over time.
- Vaccination coverage differed between first and second doses across states.
- Vaccine usage varied across Covaxin, Covishield, and Sputnik V.
- Demographic analysis reveals differences in COVID-19 distribution across age groups and genders.
- Testing and laboratory availability varied geographically, highlighting differences in healthcare infrastructure.
