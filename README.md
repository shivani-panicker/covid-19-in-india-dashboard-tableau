# COVID-19 in India – Tableau Dashboard

## Project Description
This project is an interactive Tableau dashboard that analyzes the impact of COVID-19 across India using state-wise, demographic, vaccination, and testing data. The dashboard enables users to explore trends, compare regions, and understand the distribution of cases and healthcare resources through visual storytelling and spatial analysis.

## Dashboard Features
- State-wise time series analysis of confirmed, cured, and death cases  
- Comparison of first dose vs second dose vaccination coverage  
- Vaccine-wise dose distribution (Covaxin, Covishield, Sputnik V)  
- Choropleth map showing total COVID-19 deaths by Indian state  
- Age group-wise and gender-wise demographic analysis  
- State-wise testing data and laboratory availability  

## Tools and Technologies
- Tableau  
- Spatial Data (Indian States Shapefile)  
- Data Visualization and Dashboard Design  

## Data Sources
The dashboard uses publicly available COVID-19 datasets for India, including:
- State-wise case statistics  
- Vaccination data  
- Testing and laboratory data  
- Demographic information  

## Key Learnings
- Designing multi-sheet interactive dashboards in Tableau  
- Using spatial data and maps for geographic analysis  
- Applying filters and parameters for dynamic exploration  
- Presenting complex public health data in a clear and structured manner
